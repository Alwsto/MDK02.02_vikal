# Клиентская архитектура MVVM

## View

`MainWindow.xaml` содержит элементы интерфейса: заголовок, поле фильтра по преподавателю, команды обновления и загрузки демо-данных, индикатор состояния и таблицу нагрузки. Code-behind только связывает окно с ViewModel и не содержит правил предметной области.

## ViewModel

`WorkloadViewModel` предоставляет привязываемые свойства и команды. Он вызывает `IWorkloadService`, управляет состоянием загрузки, фильтрует список, сообщает об ошибке и публикует данные для отображения. Реализует `INotifyPropertyChanged`.

## Model

`WorkloadItem` описывает строку ответа API. `WorkloadService` выполняет HTTP-запрос и преобразует JSON в модель. Демонстрационные данные используются только при нажатии соответствующей команды.

Связь слоёв: View привязана к ViewModel; ViewModel обращается к сервису и модели, но не зависит от конкретной разметки окна. Это позволяет отдельно менять интерфейс и источник данных.
