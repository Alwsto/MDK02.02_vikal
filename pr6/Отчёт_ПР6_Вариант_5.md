## Введение

Практическая работа № 6 продолжает проектирование АИС «Управление студенческой нагрузкой» из ПР1–ПР5. Для клиентского модуля определены обязанности View, ViewModel и Model, а для обмена с API описан endpoint получения расчётной нагрузки преподавателей. В проекте созданы WPF-клиент, ASP.NET Core API и файл `openapi.yaml`.

## 1 Архитектура UI MVVM

Клиентское приложение построено по паттерну MVVM. View отображает данные и передаёт действия через привязки команд; ViewModel управляет состоянием экрана и вызывает сервис; Model задаёт типизированное представление строки расчётной нагрузки. ViewModel не зависит от разметки конкретного окна.

| Слой | Компоненты проекта | Назначение |
|---|---|---|
| View | `MainWindow.xaml` | Окно со строкой поиска, командами обновления и загрузки демонстрационных данных, сообщением состояния и таблицей нагрузки. |
| ViewModel | `ViewModels/WorkloadViewModel.cs` | Свойства для привязки, `ObservableCollection`, поиск по преподавателю, индикатор загрузки, команды и обработка ошибок API. |
| Model | `Models/WorkloadItem.cs` | Модель строки нагрузки: код и имя преподавателя, подразделение, учебный год, плановые часы и статус. |
| Сервис доступа | `Services/IWorkloadService.cs`, `Services/WorkloadService.cs` | Выполняет HTTP-запрос `GET /api/v1/workloads` и преобразует JSON-ответ в модели. |

Поток взаимодействия: пользователь нажимает «Обновить» во View; команда ViewModel вызывает `IWorkloadService`; сервис запрашивает API и возвращает список `WorkloadItem`; ViewModel обновляет коллекцию; привязки WPF отображают данные на экране. Кнопка «Демо-данные» позволяет изучить интерфейс без запущенного API.

## 2 Фрагмент OpenAPI-спецификации

Ключевой endpoint возвращает расчётную нагрузку. Необязательные параметры фильтруют результат по учебному году и имени преподавателя. Полная спецификация находится в файле [`openapi.yaml`](openapi.yaml).

```yaml
openapi: 3.0.3
info:
  title: Student Load API
  version: 1.0.0
servers:
  - url: http://localhost:5080
paths:
  /api/v1/workloads:
    get:
      summary: Получить расчётную нагрузку преподавателей
      operationId: getWorkloads
      parameters:
        - name: academicYear
          in: query
          required: false
          schema:
            type: string
            pattern: '^\d{4}-\d{4}$'
        - name: teacherName
          in: query
          required: false
          schema:
            type: string
            minLength: 1
            maxLength: 100
      responses:
        '200':
          description: Список строк расчётной нагрузки
        '400':
          description: Параметры запроса имеют недопустимый формат
```

Успешный ответ содержит массив объектов с полями `teacherId`, `teacherName`, `department`, `academicYear`, `plannedHours` и `status`. Статус принимает значение «Рассчитано» или «Требует проверки». Некорректный формат учебного года и слишком длинное имя отклоняются с HTTP 400.
