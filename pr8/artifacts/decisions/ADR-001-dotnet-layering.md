# ADR-001: .NET/C# и разделение по слоям

- **Статус:** принято для учебного прототипа
- **Дата:** «____» ______________ 20____ г.
- **Связанные работы:** ПР6, ПР7

## Контекст

АИС должна предоставлять настольный интерфейс управления учебной нагрузкой и HTTP API. Правила расчёта необходимо отделить от сетевого обмена и представления, чтобы их можно было независимо развивать и проверять.

## Решение

Использовать C#/.NET. Разделить решение на `AIS.Core`, `AIS.Infrastructure`, `AIS.UI`, `AIS.Api` и `AIS.Tests`. Core содержит модели, интерфейсы и правила. Infrastructure реализует внешние взаимодействия, UI — WPF/MVVM, API — HTTP endpoint, Tests — проверки ядра. Core не имеет ссылок на внешние проекты; Infrastructure ссылается на Core; точки входа подключают реализации инфраструктуры.

## Последствия

- доменные правила тестируются отдельно от интерфейса и API;
- реализацию HTTP или хранения можно заменить за границей Core;
- UI использует MVVM, а API следует контракту OpenAPI;
- WPF-клиент рассчитан на Windows;
- текущий прототип использует демонстрационные данные в памяти; промышленное хранилище и авторизация требуют отдельного проектирования.
